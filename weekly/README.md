# Weekly Records

Weekly folders are the primary supervisor-student communication record.

## Creating a New Week

1. Copy `_template/` to a directory named `week-XX/`, using two digits.
2. Fill in the assignment before the week begins.
3. Keep the four standard documents even when one has no content yet.
4. Move confirmed project-level decisions to `project-records/decision-log.md` after the meeting.

## File Ownership

| File | Primary author | Purpose |
| --- | --- | --- |
| `assignment.md` | Supervisors | Define the task and expected outcome. |
| `student-response.md` | Student | Present analysis, evidence, and questions. |
| `supervisor-feedback.md` | Supervisors | Evaluate the response and define follow-up work. |
| `meeting-notes.md` | Assigned note taker | Record decisions and actions agreed during the meeting. |

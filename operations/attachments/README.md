# Purchase Attachments

This directory is reserved for quotations, order confirmations, receipts, and related administrative documents after the repository is private.

Before adding a file:

- Remove unnecessary personal and payment information.
- Use a descriptive filename such as `YYYY-MM-DD_supplier_item_quote.pdf`.
- Link the file from `../purchase-list.md`.
- Do not upload documents whose licensing or confidentiality conditions prohibit storage here.

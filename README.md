# Origami Locking Project

This repository records the weekly work of a master's project on active locking interfaces for modular origami robots. It is designed as a shared documentation space for assignments, student responses, supervisor feedback, meeting notes, project decisions, and administrative records.

## Project Focus

The project investigates compact and lightweight mechanisms that allow identical modular robot platforms to dock, lock, carry structural loads, and release on command. Particular attention is given to origami-integrated mechanisms and their compatibility with lightweight actuation, including pneumatic actuation.

The project remains intentionally open-ended. Literature findings, mechanism alternatives, experimental evidence, and design decisions should be recorded separately so that the final concept is supported by a traceable engineering rationale.

## Weekly Information Loop

Each folder under [`weekly/`](weekly/) contains four documents:

1. `assignment.md` - objectives, reading, questions, and expected deliverables prepared by the supervisors.
2. `student-response.md` - the student's analysis, evidence, uncertainties, and proposed next steps.
3. `supervisor-feedback.md` - feedback, corrections, decisions, and follow-up actions.
4. `meeting-notes.md` - discussion notes, decisions, action owners, and deadlines.

Supervisor and student contributions are kept in separate files. Both parties may edit their files directly on `main`; Git history provides the revision record.

## Repository Map

- [`references/`](references/) - shared reading list and reference links.

- [`project-records/`](project-records/) - decisions, open questions, and milestone status.

## Public-Phase Rule

This repository initially contains only a sanitized scaffold and public literature links. Do not add student information, meeting records, procurement details, unpublished designs, internal proposals, or confidential laboratory information until the repository has been changed to private.

No paper PDFs are stored here. Follow the external links and use institutional access where required.
